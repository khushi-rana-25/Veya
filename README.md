# EcoLab 🌿
A native iOS maternal health tracker built with SwiftUI & SwiftData.

EcoLab helps expectant mothers track and visualize their health symptoms with precision. It focuses on meaningful data insights—using interactive severity sliders and dynamic Swift Charts to create a clear "Frequency & Severity" report.

Key Features:

Symptom Logging: Interactive color-coded slider (Green → Red) for tracking symptom severity.

Data Insights: Beautiful "Glassmorphism" charts that visualize symptom frequency trends.

Offline First: Robust local storage using Apple's latest SwiftData framework.

Educational: Integrated guide for common maternal health symptoms.

## Tech Stack: SwiftUI, SwiftData, Swift Charts, MVVM Architecture.
